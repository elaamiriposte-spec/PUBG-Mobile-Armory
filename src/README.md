# PUBG Mobile Armory

An elegant and efficient online database dedicated to PUBG Mobile firearms. It offers in-depth tactical data, ballistic simulation models, and premium-quality previews of the game's top weapons.

## 🚀 Features

- **Comprehensive Arsenal**: Browse a curated list of assault rifles, sniper rifles, marksman rifles, and more.
- **Detailed Analytics**: Interactive radar charts showing weapon power, speed, range, stability, and magazine capacity.
- **Frosted Glass Design**: A modern, immersive UI with glassmorphism effects, heavy backdrop blurs, and high-contrast typography.
- **Tactical Search**: Real-time filtering by weapon name or category.
- **Responsive Interface**: Optimized for both high-end desktop monitors and mobile devices.
- **Fluid Animations**: Smooth transitions and layout animations powered by `motion`.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/) (formerly Framer Motion)
- **Data Visualization**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📂 Project Structure

- `src/components/`: Reusable UI components (Cards, Detail panels, Charts).
- `src/data.ts`: The weapon dataset source of truth.
- `src/types.ts`: TypeScript interfaces for rigid data structures.
- `src/index.css`: Custom theme definitions and global styles.

## ⚡ Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run in development mode**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
